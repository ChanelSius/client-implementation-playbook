# Client Onboarding Checklist

Use this checklist to guide a new client from contract execution through implementation kickoff.

## 1. Contract and Scope Review

- [ ] Confirm the executed contract has been received
- [ ] Review the Statement of Work
- [ ] Review Service Level Agreement requirements
- [ ] Confirm project scope and exclusions
- [ ] Identify required deliverables
- [ ] Confirm pricing, billing, and invoicing requirements
- [ ] Document client expectations
- [ ] Identify contractual deadlines
- [ ] Record assumptions and dependencies

## 2. Internal Handoff

- [ ] Schedule an internal handoff meeting
- [ ] Review sales or account management notes
- [ ] Confirm client goals and business needs
- [ ] Identify implementation team members
- [ ] Assign project roles and responsibilities
- [ ] Review known risks or concerns
- [ ] Confirm required systems, tools, and resources
- [ ] Create the internal project workspace

## 3. Client Information

- [ ] Confirm the client’s legal and business name
- [ ] Identify the executive sponsor
- [ ] Identify the primary client contact
- [ ] Identify technical and operational stakeholders
- [ ] Confirm contact information
- [ ] Document preferred communication methods
- [ ] Confirm escalation contacts
- [ ] Confirm time zones and working hours

## 4. Discovery Preparation

- [ ] Send the discovery questionnaire
- [ ] Request required documents and data
- [ ] Confirm current workflows
- [ ] Identify integration or system requirements
- [ ] Review reporting requirements
- [ ] Review staffing or user requirements
- [ ] Identify security and access requirements
- [ ] Document compliance requirements

## 5. Kickoff Preparation

- [ ] Schedule the client kickoff meeting
- [ ] Send the kickoff agenda
- [ ] Prepare the project overview
- [ ] Draft the implementation timeline
- [ ] Confirm meeting attendees
- [ ] Prepare the roles and responsibilities matrix
- [ ] Prepare the communication plan
- [ ] Define preliminary success measures

## 6. Project Setup

- [ ] Create the project plan
- [ ] Create the action item tracker
- [ ] Create the risk and issue log
- [ ] Create the decision log
- [ ] Establish document storage
- [ ] Establish status reporting frequency
- [ ] Confirm recurring meeting cadence
- [ ] Assign owners to initial action items

## 7. Readiness Confirmation

- [ ] Confirm all required information has been received
- [ ] Confirm scope is understood by both teams
- [ ] Confirm stakeholders are available
- [ ] Confirm the timeline is achievable
- [ ] Confirm responsibilities are assigned
- [ ] Confirm risks and dependencies are documented
- [ ] Obtain approval to begin implementation
